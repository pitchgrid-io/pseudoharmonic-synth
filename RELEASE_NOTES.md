# PseudoHarmonic v0.3.2

## What's New in v0.3.2

- **Double-click a knob to reset** — every knob now resets to its default value on double-click (with a "Double-click to reset" tooltip). Fixes a regression where the global pointer-events suppression during drag was swallowing the click sequence.
- **Brighter UI text** — primary and secondary text colors lifted for better legibility on the dark background.
- **New combined logo** — replaces the inline PH icon + separate "PseudoHarmonic" text with a single typeset logo (Avenir Next Condensed).
